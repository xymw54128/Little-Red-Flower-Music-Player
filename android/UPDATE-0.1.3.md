# 0.1.3 修改与验收

- 歌词：用播放器的实际播放位置逐帧驱动移动；下一行提前居中，高亮严格按 LRC 时间切换。动画最长约 480 ms，密集时间戳按间隔缩短，在时间戳前通常预留 24 ms；暂停、跳播、手动浏览后恢复均重新定位，不排队播放过期动画。移除逐行颜色/缩放动画，保留稳定排版。比屏幕一帧还密集的时间戳按实际播放时间追赶，不能承诺显示每一帧之间的所有中间行。
- 歌单：提供 8 种默认封面，新旧歌单优先分配当前较少使用的预设并保存。列表和歌单页面均可打开封面选择；系统相册选图，压缩后保存在应用私有目录。取消选图保留原封面，失败显示原因。JSON 备份保存预设，照片需另行保存和重新选择。
- 字体：保留原有 3 种，内置开源楷体、宋体、仿宋的官方字体文件和许可；无需联网下载。宋体使用上游提供的简体中文区域版；仿宋为上游 0.212 预览版。未改动或自行裁剪字体，缺失字形交由系统回退。设置预览、播放器和备份使用相同字体键，设置可查看许可。
- 兼容：同包名、同签名，版本升至 0.1.3 / 4，覆盖升级保留音乐索引、歌单与设置。

验证：歌词时间边界、不同间隔、速度与跳播的 JVM 回归测试；Android UI/持久化检查编译；APK 构建、lint、字体资源、签名及 16 KB 对齐。当前无连接手机，实机滚动帧率与系统相册操作需安装后验收。
