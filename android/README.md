# 小红花 Android · 1.0.4

原生 Kotlin / Compose / Media3 本地音乐播放器。保留 `../ui/` 作为设计参考；本工程生成真正的安卓 APK。源码已准备开源，正式签名密钥仅保存在本地。

## 安装与使用

安装包：[本地小红花 1.0.4 APK](../dist/小红花-1.0.4.apk)，包含内置中文字体。沿用旧版的应用 ID 与签名，直接覆盖安装，保留现有数据。**1.0.4 仅本地生成，尚未发布到 GitHub。** Git 克隆不包含本地 APK；已公开的 [1.0.1 APK](https://github.com/xymw54128/Little-Red-Flower-Music-Player/releases/download/v1.0.1/Xiaohonghua-1.0.1.apk) 仍可下载。当前版本名 `1.0.4`，版本号 `11`，SHA-256：**873ffb20ae1239e3a8e0d13d8e96fb3cd59b368f7d981a4b74086695796c9748**。

1. 将 APK 传到小米 15，在手机文件管理器中打开并安装。手机可能要求为文件管理器允许安装此应用。
2. 打开小红花，在 **设置 → 歌曲文件夹** 选择音乐文件，或授权音乐文件夹。文件夹递归扫描，音乐原文件不复制、不修改。
3. 音乐库右上角点搜索图标，向左展开搜索框；清除搜索后可收起。音乐库、歌单、设置三个主页可左右滑动，底部导航仍可直接切换。
4. 点歌曲开始播放；底部迷你播放器进入完整播放页。点击封面或当前歌词预览、左滑均可查看歌词，歌词右滑返回。
5. 点歌曲旁白色描边爱心后变为红色并加入“我喜欢”；再次点击取消收藏。“我喜欢”固定保留，不能重命名或删除。歌曲菜单仍可选择普通歌单再确认添加；自定义顺序需保存才生效。
6. 歌单列表或歌单右上角的相册按钮可更换封面，支持 8 种图案和系统相册照片。设置可调整歌词、颜色和封面播放页背景；歌词页为深色纯色底，歌词导入在设置 → 歌词样式中完成。文件夹页的刷新会强制重读标签。导出备份后，将音乐文件、背景与歌单照片另行保管。

支持范围：最低 Android 8（API 26），目标 Android 16（API 36）；APK 包含 ARM64、ARMv7、x86、x86_64。1.0.0 已由用户验收；1.0.1 与 1.0.4 新增交互的设备测试和验收分别记录。

## 当前限制

- 系统锁屏媒体控件由 Android / HyperOS 管理。本版设置提供系统通知设置入口，未实现独立隐藏锁屏控件的应用开关；后台播放不能通过简单隐藏通知来保留同等控制能力。[Android 官方后台播放说明](https://developer.android.com/media/media3/session/background-playback)。
- 应用未运行或系统休眠时不持续扫描；再进入主动检查。监测是通知加轮询，不能承诺所有提供者即时上报。
- 不伪造逐字歌词；当前按普通 LRC 逐行展示。M4A 等格式可读取系统支持的基础标签，内嵌歌词读取目前以 FLAC/MP3 为主，其余可配同名 LRC。
- 不保证所有音频编码、码率和异常文件均可解码；尚未进行 100 GB 真实音乐库的性能实测。
- 跨手机自动匹配依赖唯一的文件名和大小；重名同大小的多文件不会自动合并。改名、更换提供者可能形成新文档编号；跨提供者同一文件的去重仍需实测完善。
- 新手机恢复备份后需重新授权。背景与歌单照片另行导入。安卓备份格式与旧网页原型备份格式不同。

## 构建与后续升级

固定应用 ID：`com.xiaohonghua.music`。本版面向个人安装，Release 沿用 0.1.x 的本地签名身份；签名配置和密钥文件中的 `debug` 是历史命名，最终 APK 已关闭调试。密钥在 `signing/xiaohonghua-debug.jks`（已排除出版本控制），请保留并私下备份。后续版本保持相同签名并递增版本号才能继续覆盖安装；卸载会删除内部数据。[Android 签名与更新说明](https://developer.android.com/studio/publish/app-signing)。

在 Android Studio 打开此 `android/` 目录，配置 JDK 17 与 Android SDK 36。当前电脑工具已放在项目 `../.toolchain/`，不要求全局安装。

从项目根目录执行本机已配置的构建：

```text
node tools/build-android.cjs :app:assembleRelease :app:testReleaseUnitTest :app:lintRelease
node tools/package-android.cjs
```

公开源码的标准入口：在本目录运行 `gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`（macOS / Linux 使用 `bash gradlew`）。没有正式密钥时，Debug 使用标准开发签名；`assembleRelease` 生成未签名包，需配置自己的签名后分发，不会自动使用新 Debug 密钥替代正式签名。自行构建的不同签名包不能覆盖官方 APK。需要正确的 JDK/SDK 路径；构建工具和依赖初次下载需要联网，播放器运行无需联网。原工作区的构建助手在缺失密钥时会拒绝 Release 构建，避免意外生成不同签名。

SQLite 当前 schema 1；未来结构升级必须新增迁移，不能删库重建。GitHub 提供已公开的 1.0.1 APK 下载，1.0.4 本轮仅保存在本地；商店上架仍需单独确定商店签名与更新迁移方案。
