# 小红花 · 本地 UI 原型

双击 `gallery.html` 查看 22 个页面与状态总览，双击 `index.html` 操作原型。无需安装依赖，所有资源本地保存。建议使用 Edge 或 Chrome；目录授权需要浏览器支持相关能力，本地文件策略也可能影响设置和图片保存，因此目录监测建议通过本地 HTTP 服务器查看。

```powershell
cd 'D:\music player app\ui'
python -m http.server 49173 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:49173/index.html 或 gallery.html。电脑预览左侧可切换页面与手机尺寸，窄窗口自动切换成全面屏布局。

可体验歌单新建、重命名、添加与移除；音乐库与歌单内歌曲支持歌曲名 A–Z、歌手 A–Z、随机、自定义排序。中文按拼音排列。自定义排序支持鼠标和触屏拖动、键盘可操作的上移 / 下移按钮，点击“保存顺序”才写入，取消保持原顺序。随机顺序在刷新后保持稳定。“播放全部”采用所选排序。队列独立调整，不会改变歌单。

音乐库每行有数字序号，上方和底部各显示总数。主题、歌词样式、排序和示例歌单保存在当前浏览器中，备份页可导出与恢复原型 JSON。

歌曲操作或播放页“歌单”按钮会先打开目标歌单选择面板，选中后确认添加；已包含歌曲的歌单不可重复添加。选择面板中新建歌单会自动加入这首歌曲。

新版播放页居中排布封面、标题和歌词，播放页“样式”入口可直达字体、字号和背景设置。也可在设置首页进入“歌词字体与字号”和“播放背景”。

封面页左滑进入歌词，歌词页右滑返回。LRC 支持分钟 / 秒 / 小数秒、同一行多个时间戳、乱序时间戳排序，忽略非时间标签。可在歌曲信息中选择本地 UTF-8 LRC 文件（最大 512 KB），与当前歌曲绑定。歌词按时间戳高亮；手动上下浏览后暂停跟随，停止操作 4 秒后恢复居中，可点击“返回当前歌词”立即恢复。动态滚动使用约 420 ms 的缓动，页面切换约 280 ms，并尊重减少动态效果。行间距 0–48 px 可预览并保存。

播放器仍使用模拟播放时钟，不解码音频；正式版本必须将时间轴绑定到真实播放器的位置和 seek 事件。LRC offset、逐字时间标签以及更多文字编码留待正式解析器支持。

背景可选择纯色、当前歌曲封面或本地相册图片，支持 JPG / PNG / WebP（原型限制 20 MB）。图片默认等比铺满，可调节不透明度 0–100%、缩放 100–250%、水平和垂直位置。设置实时生效，背景与歌词页共用。原图单独保存在浏览器 IndexedDB 中，显示变换不修改原图；不包含在 JSON 备份里。浏览器存储被禁止时可临时预览并会显示提示。

音乐选择可读取 FLAC 标题、歌手、专辑、时长、采样率和位深；其他格式暂以文件名为主。音乐索引是本次网页会话的临时数据，刷新后需重新选择文件 / 目录。勿用原型备份承载正式音乐库；正式安卓版本需实现持久化文件索引与匹配。锁屏开关仅保存期望设置，真实系统效果尚未验证。

文件夹页有刷新和自动监测开关。支持浏览器目录授权时，原型只读访问当前目录及子目录；网页前台每 2 秒检查文件增删和大小 / 修改时间变化，每 30 秒重读 FLAC 基本标签，手动刷新立即请求完整重读。同名外部 LRC 也可同步。索引同步移除后从歌单和队列清除对应引用，文件本身不被删除；授权读取失败保留原索引。更换监测目录时丢弃旧目录未完成的扫描结果。目录句柄未持久保存，网页刷新后需要重新授权。

未支持目录授权的浏览器退回到一次性目录选择，无法自动监测。页面中的“演示增删与标签更新”仅修改示例数据。安卓后台监听、改名匹配、嵌入封面和其他格式完整标签解析尚未实现。

视觉规范与安卓适配说明见上一级 `UI-DESIGN.md`。SVG 封面与花朵标识为原创；开关结构参考本地 Galaxy 的 alexruix / lazy-dragon-53（Uiverse，MIT）， attribution 保留在 styles.css。
