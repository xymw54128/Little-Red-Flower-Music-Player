# iPhone 1.1.8 源码与双端发布

2026-10-22。沿用 main，将已确认的 Android 1.1.8 排版和歌词处理同步到既有 iOS 工程，版本 1.1.8 / build29，最低 iOS17。用户已授权将源码及 Android APK 发布至现有公开仓库。

## 范围

- 歌曲信息突出封面与明确的标题，艺术家/作曲家/专辑及音频/文件信息分组，纸色主题与少量静态花枝点缀；支持长文本和大字号，保留封面放大。
- 作曲家读取真实文件标签，默认空值兼容旧索引与备份，刷新后补读；移除信息页中专辑歌手/碟号/曲目的展示，不移除专辑排序数据。
- 核对 iOS 歌词渲染与媒体时钟链，只修正实际存在的叠层、色阶和预览时序问题；保留详情页提前完成平滑滚动的既有规则，封面单行预览按实际 LRC 时间戳显示。
- 保持 iOS 原生文件授权、音频解码和 session、DSP/音量/速度配置。复用已验证的 Android 1.1.8 APK，不为本轮移植更改 Android 生产源码。

## 验证和发布顺序

1. 并行核对元数据、歌曲信息和歌词代码，补针对性的 Swift 回归用例，审查实际 diff。
2. 更新工程生成器、检查器和打包器为 1.1.8/29，重新生成 Xcode 工程，运行语法、项目引用、scheme、资源、字体许可与哈希检查。
3. 整理 iOS 构建说明和双端下载入口，生成源码 ZIP，检查 ZIP 完整性、报告快照和 Android APK 哈希。保留 1.1.7 所有发布产物。
4. 验证待提交文件不含工具缓存、签名资料或个人数据，正常提交并推送 main，创建 v1.1.8 Release，上传 APK、iOS 源码 ZIP、校验和版本说明，复核远端资产及下载入口。

## 主机边界

本机 Windows 没有 Apple SDK，Swift grammar 和工程结构检查不能证明 Xcode 类型编译、XCTest、iPhone 排版、GPU 动画或音频输出通过。本轮提供源码，不提供 IPA；在 Mac 上可运行工程内的 `tools/verify-mac.sh` 后自行签名安装。

## 主机检查结果

工程已生成 18 个应用源码、7 个 CoreTests 文件和 1 个 UI 测试文件。27 个 Swift 文件 grammar 解析无错误；版本 1.1.8/build29、最低 iOS17、工程引用、scheme、图片和 7 份字体许可/哈希检查通过。测试发现 61 项 CoreTests（54 项纯 Core，7 项依赖 iOS 模型或 UIKit）与 9 项 UI，用例均未执行。

本轮新增 5 项作曲家和 4 项歌词回归；详情灰字的初始 secondaryLabel 自带 alpha 与动画路径返回不透明色不一致，现统一与纸色合成为不透明色，并在主题/trait 变化重刷所有行。封面预览由 UIKit 叶节点读取媒体实时进度，保留准确时间戳和隐藏停帧。Playback.swift 与核心 LRC 算法未修改。
