# 1.1.2 彩色野花整合

已获用户选择 C 彩色野花，正式落地本地 Android。沿用 main 与原签名；本轮不推送、不改 iOS。

1. 播放封面接入已选 C 的原创缓存 Canvas 花枝，封面保持静止，单行完整歌词预览与固定播放器保留。装饰绘制在照片裁剪层外，为上下枝梢预留 6.25% 外伸空间；浅深主题与主题红花颜色一致。
2. 歌词页保留右上角互动小红花，歌名－歌手两侧加入静态小型野花。长标题省略，两个48dp功能键不受挤压。歌词区域上下56dp或16%范围进行柔和渐隐，固定渐变覆盖与页面同色，不启用整页高斯模糊，不改 LRC 时钟、提前换行和1.5秒回位逻辑。
3. 整合此前本地已验收的紧密七色花迷你栏、进度圈、绿叶、收藏特效与七色花缓停，保持取消封面呼吸的结果。
4. 版本升级1.1.2/code22，构建Release/Debug/测试APK，运行JVM与Lint、同签名/无测试组件/无网络录音权限/ZIP16KB/字体资源验证，生成独立1.1.2发布包与摘要。

仅装饰及有限布局变更；不增加库扫描、音频解析或数据库迁移。原生用例能编译不等于已在手机运行；若 ADB 无设备，明确真机性能尚待验收。

边界审查：将左下最外侧蓝色小花向内收4个绘制单位，避免较宽手机屏幕出现约2–3dp裁切，保留原封面大小；网页预览同步此微调。

最终验证：Release/Debug/AndroidTest APK 构建成功，124 项 JVM 单测通过，Lint 0 错误、17 个既有提醒；91 项原生测试只编译、未运行（ADB 无设备）。版本1.1.2/code22、历史签名、7字体哈希许可、资源、权限、16KB及整合类的DEX存在性检查通过。报告为 dist/小红花-1.1.2-CHECK.json 与 dist/ANDROID-1.1.2-UI-CHECK.json；正式APK路径 dist/小红花-1.1.2.apk。

歌词标题花枝修订：左侧两朵蓝紫花，右侧三朵金/玫瑰/奶白花；共同主枝、叶片和两朵主花按180度中心对称布置，右侧多一朵点缀。原生22×28画布与48dp功能键不变，预览同步。124项单测、Lint和原生测试编译通过；320/390/430/450px浏览器检查通过。独立修订包为dist/小红花-1.1.2-歌词花枝修订版.apk，检查见dist/ANDROID-1.1.2-TITLE-SPRIG-CHECK.json；原正式1.1.2包及报告保留。

按草图再次调整歌词标题花枝：左侧主枝从外侧左上方双花簇弯向靠标题的右下枝尾，右侧以标题中心180度旋转，额外花朵使用短枝连接。左侧蓝紫两朵，右侧金粉奶白三朵；主轮廓48×36，显示44×33dp，取代此前紧凑直立小花束。歌名较长时继续省略，左右48dp功能键与歌词动画逻辑不变。原生与SVG一致，四种屏宽及中心对称检查见SKETCH-TITLE-SPRIG-CHECK.json。独立APK为dist/小红花-1.1.2-草图花枝修订版.apk，保留原正式与上一修订包。

草图版最终检查：Release构建与124项JVM测试通过，Lint0错误、17项既有提醒；91项原生用例只编译未执行。签名、版本1.1.2/code22、权限、无测试组件、16KB对齐和SHA校验通过，旧两份APK摘要核对未变。详细记录dist/ANDROID-1.1.2-SKETCH-SPRIG-CHECK.json。
