# 1.1.3 紧凑花簇标题

用户要求将歌词标题花朵聚拢、靠近文字，枝条更弯、轻包裹文字边角；五朵花应为五种不同品种且配色鲜艳，完成正式1.1.3。沿用main，本地Android发布，不推送，不修改iOS。

显示区域由44×33dp收为36×36dp，标题两侧间距由4dp缩至1dp。花朵锚点集中在靠近标题的内侧；主枝从外缘弧形托住左下角，右侧180度旋转环抱右上角，尾枝最多延伸约8dp至文字上下方。图形不参与点击或无障碍播报；ModulateAlpha使翻页渐显时枝梢不被图层边界裁切。

左2朵：亮蓝矢车菊（7组锯齿花瓣）、鲜粉蔷薇（叠瓣和螺旋花心）。右3朵：金黄向日葵（10组窄瓣、深色花盘）、朱红郁金香（杯状花冠和内瓣）、亮紫桔梗（5角花冠及浅色花脉）。枝叶改为明亮绿色，仅标题装饰改色，原封面C花框保持原样。

原生缓存轮廓与独立网页参数逐条一致，标题装饰不新增定时器或动画循环。保留现有右上小红花、48dp操作区、字体长标题省略、歌词羽化边界和LRC居中时钟。

浏览器检查：GARLAND-TITLE-CHECK.json，320/390/430/450px、5种花型、左2右3、配色、主枝中心对称、字体16.9px的长标题、遮挡和按键命中。截图c-garland-title-header.png与c-garland-title-lyrics.png。网页不代表真机帧率。
