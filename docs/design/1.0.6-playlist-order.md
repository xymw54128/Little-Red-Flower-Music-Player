# Android 1.0.6 歌单管理与顺序修复

日期：2026-10-12；沿用 main 与既有签名，只本地提交。

用户提供的六项要求作为本轮设计：页头花朵仅动画无圆形涟漪；共享排序界面清爽且可稳定拖动长列表；保存顺序持久化并同步来源相同的播放队列，保留当前歌曲、进度与播放状态；歌单详情使用收起式搜索并移除播放全部；右上菜单编辑名称/封面/简介、批量添加和移出成员、删除普通歌单；列表封面点击播放，其他区域进入详情；详情封面/名称/简介/数量可随滚动收起并在下拉时展开；歌曲菜单图标使用浅灰。

默认解释：我喜欢保留固定名称和永久歌单身份，可编辑封面/简介及批量管理成员；删除歌曲是从歌单移除，原音乐文件保留。封面点击从该歌单当前顺序第一首开始播放。编辑简介最多300字，兼容旧JSON与备份。

视觉：沿用F8F8F6底色、CE3C4C默认主题、272B29正文，浅灰菜单图标兼顾可见度。排序列表采用封面、序号、双行歌曲信息和拖动手柄，底部固定取消/保存；草稿按目标歌单稳定保存，媒体刷新不重置用户拖动。

验证：持久化、后台曲库变化合并、自定义草稿、队列来源/当前曲/进度/随机模式回归；Compose测试验证详情搜索、菜单、批量选择、封面播放与收起/展开，以及长列表排序。构建Release/Debug/测试APK与lint；无手机连接时如实保留原生UI执行与帧率验收限制。历史APK和调研文档保留。
