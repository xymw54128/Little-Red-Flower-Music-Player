# 迷你播放栏候选设计

状态：仅独立预览，待用户选择后再接入 Android；不修改 APK、iOS 或现有本地 Android 动效。当前 main 分支上的未提交工作保持原样。

## 方向与约束

以用户提供的音乐库截图为页面背景，使用原有红色 #CE3C4C、背景 #F8F8F6、深色正文及现有控件密度。保留封面、两行歌曲信息、上一首 / 播放暂停 / 下一首三个操作与 48px 控件范围。封面保持静止。只在一个花朵元素上集中动效，减少动态效果时关闭装饰动画。

## 四款候选

- A 花瓣唱片：浅红托瓣与静止圆形封面，进度沿圆弧推进。最贴近现有界面；花瓣不持续转动。
- B 花枝书签：轻薄白色整栏，细茎兼作进度，小花跟随当前位置；装饰收在下沿，叶片保持克制。
- C 花心播放键：五瓣红花直接作为播放键；点击展开、轻收拢及三片短暂花瓣反馈。
- D 七色花岛：绛红悬浮栏，暖金进度线，封面一角七色小花旋转并在暂停后缓停。对比更鲜明。

所有候选共用演示歌曲及播放时钟，仅展示交互与动效，无实际音频；无外部资源或网络依赖。页面提供四款对比与完整首页单款放大体验。

## 验证

浏览器验证 320 / 360 / 390 / 430px 单款，四款对比页桌面与手机布局，播放暂停与快速重复切换、前后切歌、长标题、进度、减少动态效果及页面隐藏。检查浏览器错误、遮挡与按钮边界。结果仅代表网页原型，不能代替 Android 帧率或真机触感验收。
