# 1.1.6 弹层修订（本地 Android / code 27）

2026-10-21，沿用 main，不推送 GitHub，保留原 1.1.6 正式 APK、摘要与报告。

## 目标和范围

共 4 处三点/排序菜单、10 处底部抽屉、5 处提示对话框和封面查看窗口。弹层沿用主页中性纸色和主题色按钮，减少带色底，统一圆角、留白及轻边框；菜单项添加用途明确的小图标。保留主题/夜间切换、长列表、键盘、安全区与编辑草稿。

## 根因及修复

默认菜单和抽屉读取 Material 的 surfaceContainer 系列角色，含 2.5% 至 7% 的主题混色，所以与主页 background 不一致。共用 OverlayUi 显式指定 pageColor 和 0 tonal elevation；不改其他界面需要的选择色。

本地 Material3 1.4.0 的 ModalBottomSheet 默认 predictive back 进度会缩放整个面板，最大横向 48dp、纵向 24dp。统一封装只关闭此抽屉默认 predictive 回调，在其 ComponentDialog dispatcher 上接普通 BackHandler：取消手势不做变换，提交后保持原尺寸向下隐藏，再卸载。基础 handler 先于内容注册，保留创建歌单子步骤的返回优先级；IME handler 在内容之后注册，键盘优先收起。横向返回不影响原生纵向拖动/遮罩关闭。

批量选歌取消按钮原先直接移除组件，改为调用现有 close，等 native hide 完成。确认、取消和完成行为仍用原业务回调，防止更名被拒绝时对话框永远隐藏。

对话框用原生 Window 动画处理进入与退出（200ms 淡入并上移 12dp，160ms 淡出并下移 8dp），避免内容提前卸载取消 Compose 动画；菜单和抽屉仍用原生持有状态及滑入/滑出，不再叠加缩放或重建列表。

## 验证边界

完成后记录构建、单元测试、lint、原生回归编译、静态覆盖及签名到 dist 的独立报告。设备未连接时不宣称原生手势、键盘或帧率实测通过。音频播放、文件管理、收藏、排序及歌词时序逻辑不在本轮变更范围内。
