# iPhone 1.1.7 源码与双端发布

2026-10-21。沿用 main。用户已确定 Android 界面方向，本轮将 iOS 1.1.1 源码同步到 1.1.7 / build28，和已验证 Android 1.1.7 / code28 APK 发布到现有公开仓库。

## 实现范围

- 原生 SwiftUI / UIKit 绘制花瓣迷你栏、右侧五叶枝条、封面野花和歌词标题小红花；取消封面呼吸，保留实心播放图标。动效按播放状态、前后台与减少动态控制，不逐帧重建全曲库。
- 爱心使用无底纹反馈，我喜欢内取消收藏先完成动画再移出；歌词标题与边界渐隐；弹层背景跟随主题并保留 iOS 原生手势。
- 音乐库/各歌单的来源、最新排序、搜索子集、跨来源重叠歌曲、随机实际队列和手动编辑顺序；排序只改队列，不重启当前音频。
- 保持原 AVFoundation 解码、音频 session、DSP/音量/速度默认行为、文件授权和库格式，最低 iOS17，iPhone竖屏。

## 验证与发布步骤

1. iOS：先核对播放调用链和 UI 文件边界，再同步源码，补顺序核心/界面测试；更新生成器和检查器版本为1.1.7/28，重新生成 Xcode 项目。
2. 运行现有 host grammar、OpenStep工程、scheme、资源、字体许可/哈希及源码快照检查；生成源码ZIP并验证完整性。Windows没有Apple SDK，不能执行 Xcode/XCTest/签名/IPA导出。
3. Android：复用 SHA-256为 `72d0860f808c1313baa9471080513f0bccf5bfb9a5ec53186ce77bd0a871b45f` 的正式APK；不为iOS移植改动已验证Android源码。保留1.1.6与iOS1.1.1历史包。
4. 检查暂存文件不含签名密钥、个人数据、工具缓存，正常提交main并推送；创建v1.1.7 Release上传ASCII文件名APK、iOS源码ZIP、校验与说明，README改为实际下载入口。

## 平台边界

iOS使用系统sheet和context menu，形态/返回手势遵循iOS，不复制Android预测返回。安装源码包仍需Mac和有效Apple签名；本轮不提供IPA，不能将静态检查等同实机性能、音频输出或SDK类型编译通过。
