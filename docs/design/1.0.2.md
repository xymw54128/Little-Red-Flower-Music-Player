# Android 1.0.2 界面与导航调整

范围：修改截图所示 Android 应用，iOS 1.0.1 源码继续暂存。本次沿用 main，不增加导航库或改变音乐文件存储。

- 音乐库标题右侧以搜索图标替代加号。点击向左扩展输入框，收起时清空检索；取消音乐库原独立搜索栏和播放全部按钮，为列表腾出高度。文件导入保留在空库提示和设置的歌曲文件夹中。
- 默认“我喜欢”置顶，不能删除/改名，可换封面、排序、移除歌曲。歌曲行白色爱心带细描边，收藏后固定红色；歌单成员是唯一收藏状态。加载/备份恢复兼容旧版本，并合并已有同名歌单。
- 主页面音乐库、歌单、设置使用同一水平分页，底部按钮与滑动同步。分组、歌单详情、设置子页和播放器独立导航；子页与弹层不参与主页面滑动。返回栈逐级返回，保留列表和播放器分页状态。
- 播放封面/歌词预览点击或左滑进入歌词，右滑返回。歌词页采用纯色主题背景，封面页的照片背景继续保留；背景选项说明限定作用于封面页。
- 检查歌曲菜单、目标歌单选择、队列、排序、封面、搜索、文件夹、主题、歌词与备份子页的进入/退出和返回路径。

验证：收藏创建/迁移/去重/取消/已删除歌曲的 JVM 测试；Release 构建与 lint；原生 UI 测试编译，并在可用的独立模拟器上执行导航检查。实际 Xiaomi 动画帧率需要手机测试，不用软件渲染模拟器推断。

版本 1.0.2 / code 9；签名沿用已安装版本，数据库 schema 1 保持。
