# 1.0.5 歌词与花朵互动

日期：2026-10-11。更新现有 Android 应用，继续使用 main 分支、本地提交和原签名，不推送 GitHub。iOS 1.0.1 与独立 Cocos 示例保留。

## 视觉

歌词页和主页共用 F8F8F6 浅色背景，移除上轮固定黑底。当前行采用主题色（默认 CE3C4C 花瓣红）、1.05 倍、透明度 1；非当前行灰色、原大小、透明度 0.6。文字布局固定，仅绘制缩放。设置预览与实际歌词一致。

Material 的 secondaryContainer / onSecondaryContainer 改为所选主题色 / 白色，因此标签与底部导航的选中填色为完整花瓣红，选择其他主题后同步改变。原默认浅紫色不再用于选中状态。

## 歌词时间线与性能

Lrc.current 继续表示真实时间戳对应行，Lrc.lead 单独表示提前呈现的视觉目标。正常播放默认提前约 300 ms 开始，结束点为下一行时间戳减去约 20 ms 的安全余量。媒体时间中的时长与余量乘以播放速度；短间隔把起点限制在上一行时间戳之后，余量至多为间隔的四分之一。

第一次进入提前窗口时，从上一帧已经显示的权重和真实列表偏移开始，剩余时长只取截止点与当前位置之差；不反向回填一个更早的起点。颜色、缩放与居中使用同一 easeOut 进度并同时结束。实际时间戳到达时目标已相同，不重新启动第二次动画。中途切换速度重新计算截止点，从当前画面接续；减速后不会退回已经离开的旧行。

自然播放逐帧读取 MediaController.currentPosition，以媒体时间采样，暂停后冻结。暂停时主动跳转、手动回位及页面恢复使用约 300 ms 单调时钟过渡；进度跳转以最后真正呈现的状态为起点，不能用跳转后的新媒体时间采样旧过渡。Media3 discontinuity 与本地 seek 请求识别跳转，不把主线程延迟帧或倍速变化误当成 seek。

LazyColumn 只布局可见歌词，所有行仍按相同字体、字号、译文及实际宽度提前测量。真实高度前缀用于计算绝对滚动位置，两端半屏 padding 使首末行也可居中。灰色和主题色各是一层固定字形：灰层 alpha 恒定 0.6，彩层 alpha 为权重 w，源覆盖合成后的透明度为 0.6+0.4w；不逐帧改变文字颜色、字重或字号。每一段动画只保留一个有效实例，密集时间戳或连续 seek 从上一帧续接。

手动触摸与惯性滚动优先；结束后 1.5 秒自动回位。动态歌词关闭时高亮继续，但自然播放不自动滚动；进入、主动跳转及回位仍定位。主动 seek 不能提前呈现尚未发生的用户操作，因此跳转自身采用平滑过渡。时间戳密集到短于显示帧，或系统发生长帧时，无法保证每条中间行都被屏幕显示；最终目标不排队延后。

## 封面

新增桃枝、雏菊、郁金香、铃兰、鸢尾、向日葵、山茶、绣球、荷风、蓝罂粟，使用不同花型、自然曲线和统一浅底色。喜欢专用“心之花”结合歌单页五瓣红色轮廓、金色花心和爱心。11 份矢量无需网络，尺寸缩放不模糊；实际路径预览见 [封面预览](../../dist/歌单花朵封面-1.0.5.png)，此图不是 Android 界面截图。

旧预设编号 0–7 保留，新花型为 8–17，收藏封面为 18，共 19 项。新普通歌单优先分配少用的新增花型。“我喜欢”旧默认、无照片的封面仅迁移一次；相册照片及其他已选图案保留，之后改回旧编号也不会再次迁移。旧数据没有记录是否手动选择过默认编号，所以与原默认编号相同的封面会在首次升级时更新。

## 页头互动

三个小红花均为 48 dp 点击区域、居中 36 dp 图形，复用实际五瓣轮廓，不添加底纹。音乐库花先加速再缓慢制动，最后回到原方向；歌单花淡出旧轮廓，显现黄蕊后沿路径重新描线；设置花五瓣离开花心，再按顺序归位。每个完整序列为 2 秒。

每次点击采样当前姿态作为新起点，取消旧 generation 并启动新序列；不会忽略快速点击或堆叠完成回调。路径与方向缓存，进度在绘制阶段读取，不逐帧布局。后台暂停时钟；系统动画倍率照常尊重，关闭动画时直接显示静态矢量。结束后直接绘制原版矢量，保持落位图形一致。启动飞花仍以音乐库外层图标中心为终点。
