# Android 本地播放页动效调整

基于 Android 1.1.1 / code 21，仅做本地预览；iOS、正式发布产物和 GitHub 保持原状。

## 交互约定

- 封面取消自动呼吸缩放，保留点击进入歌词的操作反馈。
- 播放页、音乐库及歌单歌曲列表复用同一个喜欢按钮：取消灰色圆形按压底纹，点亮与取消提供不同方向的轻弹、微倾斜和花瓣反馈。首次进入页面不主动播放收藏动画。
- 音质信息旁的三条律动线替换为七瓣七色花，使用彩虹花瓣与金色花蕊，无底纹。
- 稳态旋转速度为每秒 48 度；启动约 240ms 平滑提速，暂停约 900ms 平滑减速至零，保留停止角度。快速切换播放状态沿当前角度与速度继续。
- 动效不依赖播放进度 tick，不引入音频分析、图片资源或新依赖。页面隐藏、退后台和系统关闭动画时不持续绘制。

## 验证与验收

构建、JVM 测试、Lint、原生测试编译及本地 APK 签名检查结果记录在 `dist/ANDROID-LOCAL-PLAYER-MOTION-CHECK.json`。原生测试编译不等于设备上执行。

手机验收：

1. 播放超过十秒，确认封面大小不再周期变化；点击封面仍可进入歌词。
2. 在播放页及歌单歌曲列表快速点亮、取消喜欢，确认无灰色圆底纹、反馈可重入、收藏状态正确。
3. 播放时七色花稳定旋转；暂停后逐渐停止，反复切换播放/暂停不归零或跳角。
4. 切换歌词页和后台再返回，确认花朵位置连贯，后台不保留无用动画循环。
5. 系统关闭动画后花朵静止且操作正常，重新开启动画后恢复。

本轮不为视觉修改单独递增正式版本号；本地 APK 使用独立文件名，不覆盖已发布 1.1.1 安装包。
