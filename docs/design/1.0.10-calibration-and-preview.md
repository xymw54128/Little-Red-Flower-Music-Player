# 1.0.10：歌词校准移除与待选设计

2026-10-14。实际应用仅取消手工歌词时间校准；新字体和播放页先做预览，等待用户选择。继续当前 `main` 分支，本地提交，不推送。

## 已授权的应用变更

移除设置滑条、状态、持久化及 JSON 备份字段和播放时偏移换算。忽略旧的手工偏移；保留标准 LRC `[offset:]` 元数据、现有提前换行、暂停继续和拖动进度行为。音频文件不改。旧偏移、备份兼容和原始时间匹配有回归；保留标签/LRC 缓存检查。

## 播放页预览取向

延续花瓣红 `#CE3C4C`、主页浅色 `#F8F8F6`、文字 `#252B27`、可读次要文字 `#687263`。示例封面以叶绿和自然粉色辅助，标题与控件有清晰层级。全面屏布局保留顶部与底部安全区域，操作至少 44 像素。减少动态设置关闭持续动效。

| 方案 | 布局与动效 | 取舍 |
| --- | --- | --- |
| A 花瓣唱片 | 居中的圆形唱片，播放缓转，唱臂落位；暂停冻结角度 | 仪式感强，原方形封面会裁切 |
| B 封面画廊 | 大封面、左对齐歌曲信息、近拇指控件；仅封面轻微呼吸 | 完整展示封面，结构更稳妥 |
| C 花开声场 | 五瓣圆滑花形封面与轻微舒展轮廓 | 小红花品牌更突出，会裁切原封面 |
| D 双页诗笺 | 小封面与标题，三行歌词居中，克制的封面轻浮 | 歌词更显眼，封面占比小 |

四种共用模拟进度、切歌、收藏、队列和歌单选择；点击或左滑进入完整歌词，右滑返回。原型不播放音频，不接触 App 数据，也没有恢复已删除的自定义照片背景。封面和短歌词为原创演示素材。

## 字体预览原则

展示六种新方向与现有文楷/宋体对照。仅下载官方许可清楚的真实字体字形子集，记录原来源、许可、哈希、实际覆盖和配套语种。主字体原生缺字与配套字体分开标注，不能把系统回退写成原生全覆盖。子集只供预览；选定后才决定完整字体、跨语种搭配与 App 包体取舍。
