# iOS 1.1.1 同步与验收范围

2026-10-15，最低 iOS 17 / iPhone，版本 1.1.1、构建号 21。沿用原生 SwiftUI / UIKit / AVFoundation 工程，不引入第三方播放器或 UI 依赖。

本次将原先 1.0.1 源码同步当前已确认方向：原版 B 固定大封面、一行完整滚动歌词、已播放/总时长、默认我喜欢、歌单描述与批量管理、收起搜索、主题与夜间模式、八种字体、花朵互动、手动完整标签刷新，以及千首数据处理。保留 iOS 文件授权、后台音频、锁屏指令、JSON 备份和启动动画。

## 实现取舍

- 固定封面页使用可用空间决定封面大小，先保留歌词与控制区。歌词预览由独立小视图观察播放进度，长文本使用 Core Animation 平移已排版的 UILabel；减少动态时可手动横向查看完整文字。
- 完整歌词使用统一 CADisplayLink 时钟同时计算居中、主题色、透明度与缩放，目标时间戳前完成。1.5 秒回归；seek 和重新进入以歌曲、排版与跳转代数区分，打断旧过渡。
- 主页使用系统 TabView 与底部导航，横滑松手后切换；只在根页面允许，排除左侧系统返回区域。没有声称已实现 Android 式随手指连续分页。
- 文件扫描/标签解析在 actor 后台，新增来源批量合并并一次发布；手动刷新强制读取所有标签，取消不会发布半成结果。FLAC 未知填充块直接跳过。
- 后台预建排序、原文/拼音/首字母索引并复用未变项；以 Song ID 稳定去重。专辑按 albumArtist（缺省 artist）区分，FLAC/MP3 读取盘号/曲号；其他格式未取得时使用空/0 默认值，不编造标签。
- 封面按展示尺寸后台采样，24 MiB NSCache、最多双并发，离屏取消跳过尚未开始的旧请求；内容变化改文件名避免旧缓存串图。
- 播放进度写入独立 playback.json，避免定时序列化千首歌词库；来源排序更改同步队列而不重启当前音频。保存有 revision 防止旧任务覆盖新结果。
- 新字段使用显式缺省解码兼容 1.0.1。旧监测/播放背景字段仅用于读取旧数据并归一关闭，移除相关设置入口；已有原音乐和照片不因升级被删除。
- 7 份字体与 Android 1.1.1 字节/哈希一致，保留 OFL 来源。两款字库缺少中点标点，明确回退到文楷并在资源报告中记录；其余未覆盖字符由系统回退。

## 验证

Windows 执行独立 tree-sitter Swift 语法解析、OpenStep 工程解析、target/source/resource/scheme 引用、版本/最低系统/无预填签名团队、隐私 XML、图标、7 字体哈希/名称/许可和样本文字检查，以及源码 ZIP 完整性与 Android APK 不变校验。

39 项核心测试和 7 项 UI 用例已提供，但未执行。补充了旧 JSON 兼容、千首去重与顺序、收藏、轻量状态、拼音、专辑标签、FLAC padding、LRC 过渡、播放队列、总时长、固定封面和导航场景；旧备份测试改为按歌单 ID 定位，避免新增默认收藏后误把第一项当成原歌单。

Xcode SDK 类型检查/编译、XCTest、iPhone 模拟器、签名/IPA、真实千首 FLAC / 100 GB 曲库、帧率/内存和后台锁屏均未验证。可在 Mac 运行 ios/tools/verify-mac.sh 继续；语法与工程检查不能替代上述验收。
