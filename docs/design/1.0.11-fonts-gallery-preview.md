# 1.0.11：已选字体与封面画廊增强预览

2026-10-14。用户选择上一轮字体 A/B/C/D/F；播放页继续在 B「封面画廊」上加细节，先预览再确定。实际 Android 仅应用字体选择，播放页仍保持已有布局。当前 `main` 分支，本地提交，不推送。

## 字体

加入站酷小薇、Zen Maru Gothic、Kiwi Maru、Zen Kurenaido、龙藏手书，保留系统、文楷与宋体，共八项。替换花间萌趣和圆润手绘，旧选择迁移到本轮相近样式。使用完整官方原字库及有许可的语种配套，绝不把上一轮试读子集当生产字体。保留离线、Android 8+、单 Typeface 的 Compose/原生歌词一致性；检查 GB2312、假名、现代韩文与英数。记录完整来源、补字规则、许可与打包体积，罕见字回退不冒称全部 Unicode 覆盖。

## 播放页候选

沿用花瓣红 `#CE3C4C`、浅色主页 `#F8F8F6`、正文 `#252B27`、次要文字 `#687263`。保留 B 的大封面、左对齐歌曲信息、底部播放控件和轻触/左滑歌词入口。增加的深度来自封面区域，持续动效只在播放时运行，不恢复自定义照片背景。

| 方案 | 主要视觉变化 | 动效 |
| --- | --- | --- |
| B1 花影浮光 | 叠层画框、主题花角标、队列曲号 | 画框轻浮与花朵轻摆 |
| B2 呼吸声纹 | 原大封面下方的一条细腻声纹 | 声纹随播放状态流动，暂停冻结；原型只是示意，不分析音频 |
| B3 花笺留声 | 花笺式封面与下方歌词题签 | 花朵轻摆、题签随歌词更新 |

三个方向共用下一首入口、来源与队列位置、进度时间浮标、切歌过渡、收藏局部花瓣与播放按钮短回应。避免同时叠加所有装饰。连续切歌取消旧过渡；减少动态设置关闭持续及交互动画。布局只用于预览，用户确认后才移植 Android。

## 验证

字体来源与完整字形覆盖、许可和 APK 资源检查；JVM/Android 构建及 Lint。原型检查三种方案的播放暂停、快速切歌、下一首与队列、收藏、歌词、浮标、主题与减少动态，并验证四种屏幕尺寸及截图。浏览器动效不等同于 Android 真机帧率；没有设备时明确原生测试只编译。
