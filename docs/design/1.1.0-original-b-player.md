- 使用 docs/previews/2026-10-14/player-options/ 中最初 scheme=B。保留当前主题浅深背景、文字与主题色；不采用后续材质边框。

- 固定封面外轮廓，仅图像播放时做9秒1→1.025→1轻呼吸；暂停、歌词页、后台或系统关闭动画时停止。

- 沿用现有LRC解析与提前同步换行、1.5秒回位、字体、队列、库与备份逻辑。
