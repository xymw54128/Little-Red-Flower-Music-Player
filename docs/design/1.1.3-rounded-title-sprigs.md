# 1.1.3 圆润花枝修订

2026-10-20。用户进一步要求减少花枝弯曲，左花朝上、右花朝下，花朵与枝叶统一为小红花主题，并适配不同长度的歌名。本地 Android 修订，不推送 GitHub，不改 iOS，沿用 main。

标题两侧仍各占36×36dp、间隔1dp，左2朵/右3朵。统一使用 App 图标的圆润五瓣轮廓与黄色花心；左红粉、右蓝金紫，配实色饱满绿叶。枝条改成舒缓斜向，右侧共用枝形180度旋转。取消原先8dp越界卷枝，所有图形均在装饰范围内，避免遮挡大字号文字。花枝静态缓存，不新增持续动画。原 C 播放封面花框及歌词时钟不变。

短的歌名与歌手组合保持居中，花枝跟随文字靠拢；长标题在两簇花之间单行裁切并缓慢滚动，保持13sp字号，以24dp/s展示完整文字，开始和每次重播前等候1200ms。只在歌词可见、应用前台时滚动，返回/右上小红花维持48dp操作区。标题文本保留完整无障碍语义。

验证：网页覆盖320/390/430/450px，8种长短中英日韩及emoji样本、13/16.9/26px共96种组合；花朵不遮字、不越界，按钮可命中，长标题实际滚动且离开歌词页停止。原生与网页轮廓及参数独立核对一致。最终 APK 构建结果与真机边界见 dist/ANDROID-1.1.3-ROUNDED-TITLE-CHECK.json。网页不代表原生渲染或帧率。
