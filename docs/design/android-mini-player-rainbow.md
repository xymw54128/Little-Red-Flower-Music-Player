# Android 七色花迷你播放栏

用户选定 A 圆润播放栏，并要求铺满两边、D 七色花瓣环绕封面旋转轻跳、暂停缓停、A 环形进度与原有按键。仅本地 Android，版本仍基于 1.1.1 / code 21，不推送 GitHub，不修改 iOS。

## 实现

- 26dp 圆角 Surface 占满可用宽度，无左右外边距。高度至少 84dp，随系统字号自适应，保留三个独立 48dp 点击区。
- 64dp 装饰区域中，40dp 缓存封面保持静止；七片 D 配色花瓣加宽为相邻略微交叠的圆润轮廓，依次轻跳，固定瓣根，只让瓣尖伸展至多 1.5dp。进度圈半径 20.8dp、描边 1.6dp，内缘正好贴合 40dp 封面，最后叠加绘制，跟随主题色。
- 复用 PlaybackFlowerMotion：播放时每秒 48 度，240ms 提速、900ms 缓停；起伏幅度同步随速度收敛，快速切换不重置角度。每圈两轮七瓣接力，稳定速度时每瓣约 536ms；单瓣 sin² 脉冲，首尾速度为零，不做真实音频节拍检测，不申请录音权限。
- 花瓣和进度只更新小区域，路径和图片缓存复用；后台、系统关闭动画及暂停静止后挂起，不忙循环。
- MiniPlayer 在局部收集 model.playback 的真实进度。MusicApp 继续过滤 position tick，避免整库或导航每 100ms 重组。暂停、seek、未知时长与切歌过渡均正确处理。
- 上一首、播放/暂停、下一首沿用 MusicModel；按钮触摸与点击整栏打开播放器相互独立，沿用原有返回路由。

## 贴边与绿叶精修

右上、左下各两片绿叶与短茎、细叶脉固定在边框，路径使用 drawWithCache 缓存，无额外点击节点。照片、真实进度与原有 48dp 按键保持原行为。

POLISH-CHECK.json 在 320 / 360 / 390 / 430px 核验了圈内缘与照片半径一致、中心重合、瓣根半径稳定、同一时刻最多一瓣伸展并按 0..6 顺序、缓停后全部回到静止、四片叶子与按键区域。该检查是网页原型验证，不代替原生手机执行。

## 紧密花瓣微调

仅加宽七片花瓣的轮廓，让相邻边缘自然交叠，保留 64dp 装饰区域、40dp 封面、进度圈、逐片跳动和缓停时钟。静止及最大跳动时，圈外 21.6–25dp 半径范围的角度采样未见间隙；最大外半径约 31.53dp，在 64dp 区域内。
