# 小红花 Android 1.0.3 交互优化

日期：2026-10-11。作者：浪雨林兴云魔王。当前 main 分支，本轮只生成本地安装包与提交。用户确认“完成介绍”指操作完成反馈，本轮不增加新手引导。

## 设计方向与资料

保留小红花已有的简洁页面、红花主题、黄色花心和原生触控方式。增强操作与结果之间的连续性：按下有触感、选中有状态、拖动跟随手指、松手自然落位、完成有明确反馈。

- [Material 3 动效规范](https://m3.material.io/styles/motion/overview/specs)和[官方动效系统介绍](https://m3.material.io/blog/m3-expressive-motion-theming)：空间变化使用弹簧，颜色和透明度使用短过渡。本项目据此选取克制参数，使用当前 Compose 的稳定 API，无需引入新动效依赖。
- [Apple 动效指南](https://developer.apple.com/design/human-interface-guidelines/motion)：反馈简短、有目的，方向符合手势预期，操作无需等待动画结束。本轮仅借鉴原则，改动范围为 Android。
- [Compose 点击与交互状态](https://developer.android.com/develop/ui/compose/touch-input/user-interactions/handling-interactions)：共用原生点击的 InteractionSource 与涟漪，滑动取消按压时不误触点击。
- [Compose 绘制阶段动画](https://developer.android.com/develop/ui/compose/animation/value-based)：缩放、位移、透明度优先在图层或绘制阶段读取，避免把按钮动画传播到整个页面。
- [Compose 列表动画](https://developer.android.com/develop/ui/compose/touch-input/user-interactions/swipe-to-dismiss)：稳定项目 ID 配合 animateItem，顺序变化和移除连贯呈现。歌曲行不增加横向删除手势，避免与主页横滑冲突。
- [Compose Slider](https://developer.android.com/develop/ui/compose/components/slider)：连续值由本地状态预览，在 onValueChangeFinished 提交保存。
- [Compose Snackbar](https://developer.android.com/develop/ui/compose/components/snackbar)：保存与添加完成采用非阻塞提示，可恢复的删除附带撤销按钮。

## 实现范围

| 操作 | 视觉与触控反馈 | 数据行为 |
| --- | --- | --- |
| 图标与列表点击 | 图标按下轻缩放、原生涟漪、自然回弹；行缩放更轻 | 操作不等待动画，滑动取消按压 |
| 收藏 | 白色爱心到红色的短过渡，轻微弹动及一次触觉 | 即时同步“我喜欢”，快速连续操作替换旧提示 |
| 主页和子页切换 | 主页跟随原生分页手势，导航图标轻变化；子页返回方向相反 | 延续已有返回历史与保存的分页状态 |
| 播放与进度 | 播放/暂停图标短淡入；页指示器命中区域 48 dp；松手定位一次触觉 | 不更改播放时钟、LRC 时间戳和提前换行算法 |
| 排序与队列 | 长按拾起、浅底色与轻抬升；相邻行平滑让位；边界限位和松手归位 | 自定义顺序保存后生效；队列操作按实时 ID 定位 |
| 歌单添加 | 同一底部面板内切换选择与新建；选中底色、键盘完成、防重复提交 | 提交时重新检查目标与成员，成功才显示完成提示 |
| 删除与移除 | 列表行消失与余下行移动；深色圆角提示配花心黄色的撤销入口 | 删除歌单、移除歌单成员可撤销，保留后来编辑，过滤已不存在的音乐 |
| 歌词/背景设置 | 拖动实时预览、当前数值强调，选项状态短过渡 | 松手一次保存，减少 JSON 写入和全局状态更新 |
| 封面选择 | 选中边框和勾选过渡，明确“完成”出口 | 选中立即应用，完成只提示确认；照片原导入流程保留 |

触觉只在收藏、切歌、模式切换、确定、排序跨行和设置提交等节点触发，使用 Android 原生触觉接口并遵守系统触摸反馈设置。新增动画由 Compose 管理，遵守系统动画时长比例；不使用持续装饰动画，也不额外添加逐字歌词效果。反馈包含文字和选中语义，动画不是唯一状态信息。

## 撤销边界

删除歌单记录原 ID、位置、封面、排序与成员。恢复时不覆盖相同 ID 的现存歌单，不恢复已从音乐索引消失的歌曲。移除成员的撤销只补回该首歌，用原顺序中仍存在的邻居确定位置；后续改名、换封面、排序或添加其他歌曲均保留。默认“我喜欢”仍不可删除或改名。

提示仅保留当前操作，避免排队显示过期成功信息；后续操作可替换前一条撤销入口。执行备份恢复前清除旧撤销提示。原音乐文件不参与删除或撤销。移除文件夹和队列不提供数据撤销，完成提示依据实际操作结果。

## 验证与交付

新增 JVM 测试覆盖恢复位置、元数据、后续编辑、重复恢复、已删除音乐和默认歌单保护。原生界面回归包含滑条松手提交、防重复添加、面板返回、排序边界与真实撤销流程。

构建、单元测试、lint、测试 APK 编译及最终包签名/资源检查的实际结果见 [1.0.3 包检查](../../dist/小红花-1.0.3-CHECK.json)与[原生 UI 执行状态](../../dist/ANDROID-1.0.3-UI-CHECK.json)。当前未连接 Android 手机，现有软件模拟器此前未能启动；本轮没有原生 UI 运行或帧率测量，编译成功不能证明触摸手感。

小米 15 / Android 16 验收重点：连续左右切换与返回、快速收藏、键盘完成与双击、滑条拖动/松手、排序首尾限位和释放、密集时间戳歌词、删除后撤销、TalkBack、关闭系统动画和触觉。另需观察大音乐库滚动。iOS 1.0.1 源码与网页原型保持原有状态。
