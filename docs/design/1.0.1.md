# 小红花 1.0.1 界面改进

以已验收的 1.0.0 为基线，沿用应用 ID、签名与数据结构，仅修改本次五项需求。

- 迷你播放器采用上一首 / 播放暂停 / 下一首三个按钮，完整播放页已有的上一首继续保留。
- 音乐库与歌单歌曲列表右下角，在用户滚动时渐入定位按钮；停止滚动 2 秒后渐出。仅在当前列表含播放歌曲时显示，点击将该行移到列表中央附近。不改变搜索、排序或播放队列。
- 新启动动画约 2.64 秒：黄色花心 → 五瓣依次从花心长出 → 小幅转动 → 沿弧线快速旋转并缩小，飞至音乐库标题旁原有小红花 → 再小转动落稳。截图的标题花位于左上角，本轮按该现有位置作为终点。
- 品牌色沿用红 #CE3C4C、金 #F6D88C、页面 #F8F8F6、正文 #272B29、次要文字 #696F6B。“小红花 · 音乐播放器”使用离线霞鹜文楷、轻斜体与适度字距，24 sp 红色手写字；第一个花瓣长出时渐入，花离开中央后渐出。复用已授权字体，不额外下载字体。
- 使用原生 Compose 的绘制和图层变换、缓存原版矢量与扇区路径、单一帧时钟。页面在动画下方正常布局；测量标题花实际位置后落位，避免按机型硬编码。前后台暂停帧时钟，旋转屏幕与从后台恢复不重播；尊重系统关闭动画的设置。
- 进度条根因：自动文件监测每 5 秒刷新，直接令 library.busy 变为 true，主界面据此显示进度条。保留扫描忙碌状态，增加“用户发起的可见扫描”状态，自动检查静默同步；手动导入与刷新继续反馈进度。
- 设置关于区域署名“作者：浪雨林兴云魔王”。

验证：保留原有测试，新增启动时序、边界连续性及不同帧间隔采样测试；扩展原生 UI 测试覆盖迷你上一首、定位按钮与署名；构建 Release 与仪器测试 APK，核对最终签名、版本、资源和 16 KB 对齐。当前电脑无连接手机，资源预览和时间数学不代表实机帧率验证。
