# 原 B 封面材质边框：调研与独立预览

日期：2026-10-15。范围：保留最初 B「封面画廊」的页面构图，重新设计封面外缘；等待用户选择，不修改 Android 播放页。

## 设计约束

- 封面本体、歌名、歌手与专辑、歌词预览、进度条和播放控制保持原 B 的位置与尺寸。
- 新装饰仅在封面外缘绘制，中央封面不加滤镜、不改变原色；界面提供「原版 B」直接对照。
- 边框的质感来自倒角、内切、明暗反射和局部光学层次。避免整圈均匀渐变、RGB 跑马灯、粒子和满屏玻璃。
- 原型使用项目内原创示例封面。参考材质原则，不复制第三方卡牌图、品牌界面或着色器代码，不引入运行时依赖。

## 三个材质方向

1. **水晶透镜**：明确的弧面厚度、内侧窄暗缝与外缘亮口。使用封面自身的边缘颜色形成侧壁映色，仅在外缘做少量 RGB 采样偏移，中央图像保持清楚。
2. **铂金切面**：哑光外肩与镜面内切共用一个交互光源。宽反射面、窄切线和适度暗的内缝形成截面层次，微纹理只作近距离细节。内缝不应成为贯穿四边的黑色密封条。
3. **珠光镀膜**：温白基底占主要面积，只在局部受光位置出现低饱和雾粉、浅金和冷青。薄膜光泽随表面方向和指针角度改变，保留微细纹理与内外缘高光，避免形成连续的整圈彩虹。

## 渲染与静态回退

原型位于 `docs/previews/2026-10-14/material-frames/`。`material-renderer.js` 是本轮原创 WebGL 片元着色器，只在封面轮廓之外约 11.5 CSS px 的区域着色。圆角距离、外向方向和截面曲率共同生成法线，再计算定向反射、局部高光与三种材质的不同响应。画布透明区域让原有 DOM 封面继续显示；文字和按钮仍是原 B 的 HTML。

画布按封面尺寸调整，像素比上限 1.5，使用单个矩形绘制，光照变化通过统一变量更新。切歌时用当前示例封面更新侧壁采样纹理。上述属于实现约束，不构成真实手机帧率或耗电保证。

浏览器无法创建 WebGL、着色器初始化失败或发生上下文丢失时，显示 CSS 静态材质外框。静态回退保留轮廓和基本明暗，没有实时反射，不能与 WebGL 材质的视觉表现等同。

## 动态边界

| 状态 | 行为 |
| --- | --- |
| 正在播放、封面可见 | 光源有低幅度缓慢变化；指针或手指位置可改变受光方向 |
| 暂停 | 停止自动光照时间；直接触摸或「演示一次光线」仍可产生短暂反馈，反馈收敛后停止连续绘制 |
| 切到歌词页 | 停止边框的连续绘制，不在不可见封面上持续运行 |
| 浏览器标签页隐藏 / 离开页面 | 停止请求下一帧；重新可见后按当前页面和播放状态决定是否恢复 |
| 系统启用减少动态 | 停止自动光照循环及时间驱动演示，直接采用当前交互位置绘制静态状态，不做持续缓动 |
| 切回原版 B | 隐藏材质画布与装饰并停止材质连续绘制 |

本轮提供「演示一次光线」、切歌、主题切换、原版 B 对照以及整页/局部比较，便于用户判断材质效果。浏览器演示没有真实音频，光照不是对音频波形的分析。
