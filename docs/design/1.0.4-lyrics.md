# 1.0.4 歌词同步与界面精简

日期：2026-10-11。修改现有 Android App，并提供独立的 Cocos Creator 3.8 TypeScript 示例。只保存本地提交和安装包，暂不推送 GitHub。

## 界面

歌词页顶部只显示“歌名 - 歌手”与收起入口。删除导入歌词、歌词字体设置、添加歌单和回到当前按钮；播放进度、播放控制和封面/歌词分页保留。导入当前歌曲歌词移至设置 → 歌词样式，没有当前歌曲时禁用导入。

当前行使用白色、透明度 1、缩放 1.05；非当前行使用浅灰、透明度 0.6、缩放 1。歌词页采用固定深色纯色背景，避免白字在浅色底上不可读。封面播放页仍保留已有背景设置。页面顶部与播放控制区随歌词页切换为相应颜色。

收藏、取消收藏、加入歌单、新建歌单和新建并添加不再产生成功消息；爱心、选中状态、列表更新及原触觉反馈保留。重复添加与失败继续说明原因；删除和移除的撤销入口保留。

## 时间与动画

旧算法在下一行时间戳前开始滚动并完成居中，颜色却到时间戳才切换。例如 5 秒的新行在约 4.976 秒已居中，直到 5 秒才高亮。远距离定位还会调用直接跳行，造成跳动。

本轮以新的 LRC 时间戳或主动跳转作为同一轮过渡起点：颜色、透明度和缩放在 250 ms 内完成，居中在 300 ms 内完成，使用同一个单调时钟和 cubic easeOut。保留用户指定的两种时长，因此样式比位移早 50 ms 完成，二者从同一帧、向同一目标行变化。自然播放中显示帧略晚时根据实际播放位置追赶；不提前点亮未来歌词。

只有一个帧循环和一段有效过渡。遇到密集时间戳、连续跳转或反向跳转，替换旧过渡并保存当时的高亮权重和实际滚动偏移；未完成的旧行可以继续淡出，不重新变成完全高亮，不排队补播中间行。暂停停止媒体时间，已启动的 UI 过渡仍可完成；暂停时跳转同样有动画。

歌词以 ScrollView/滚动容器和独立文本行展示。字体、字号、行距、译文和换行参与行高测量，缩放只改变绘制，不改变行高。容器两端留半个视口的空白，使首末行也能垂直居中。首次排版直接使用当前行的初始偏移，显示后不先跳到旧行再修正；后续位移只平滑滚动。逐帧读取延迟到文本绘制和图层，非变化行的权重使用独立派生状态。

手动触摸或惯性滚动期间让用户操作优先。两者结束后无操作 1.5 秒恢复跟随，约 300 ms 平滑回位；计时与帧调度仍受系统调度影响。进入歌词页或主动跳转会恢复跟随。动态歌词开关关闭时保留时间戳高亮，取消自然播放自动滚动；主动跳转、进入与手动浏览回位仍定位当前行。

LRC 解析支持多时间戳、offset、毫秒精度及同一时间的译文合并。数据包含 startTime、endTime、text，endTime 取下一行开始时间，末行取有效歌曲时长；未知时长保留开放区间。Android 保留 time 字段兼容原调用，TypeScript 使用秒。

## 独立 TypeScript 示例

完整脚本和节点结构见 [examples/cocos-lyrics](../../examples/cocos-lyrics/README.md)。示例适用于 Cocos Creator 3.8 的 ScrollView、Label、AudioSource 和属性面板；没有要求用户先决定引擎，也没有把原生 Android 工程替换为 Cocos。时长、颜色、字号和行距可在属性面板调整。
