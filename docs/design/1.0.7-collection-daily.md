# Android 1.0.7：收藏、歌词与日常使用

日期：2026-10-12。延续 main、已有应用签名与离线定位。用户要求调研的三组功能一起开发；本轮仍仅本地提交。

## 本轮可见结果

- 音乐库、歌单与批量选择支持中文、英文和文件名搜索；Android 10 及以上另支持完整拼音与拼音首字母，Android 8/9 保留原词检索。转写在后台增量缓存，原文匹配立即可用。
- 读取专辑歌手、盘号、曲号；合集按专辑歌手聚合，多碟专辑按数值盘号与曲号播放，旧文件无新标签时沿用歌手。
- 歌曲菜单提供下一首播放、追加队尾；不重启当前歌曲，保留进度与播放模式，已有歌曲移动不重复。手动修改队列后与来源排序隔离。空队列添加保持暂停。
- 设置 → 歌词样式提供当前歌曲独立校准，±10秒，正值表示歌词延后；改变歌词时钟，不改变音频进度，点击歌词跳转按同一偏移换算。数据按歌曲ID保存并纳入备份。
- 音乐/LRC增删改增量检查；未变化不强读所有音频标签，前台15秒、后台播放60秒检查。通知防抖保留，手动刷新和升级首次新标签读取为完整校验。提供者不更新修改时间时用手动强刷。
- 睡眠计时提供15/30/45/60分钟与取消；使用单调时钟，后台服务到时暂停，服务销毁后清除，不跨重启恢复过期计划。设置与播放封面页均有入口。
- 可切换夜间主题，覆盖主页、子页、歌词、播放控件、弹层及启动底色；默认浅色，花朵品牌与可读主题色保留。
- 最近播放记录本机实际开始播放的歌曲，最多100首、去重且最近在前；暂停恢复/进度更新不制造记录。提供清空确认并保存/备份。
- 用户追加：列表副标题为歌手 · 专辑名；歌单卡片显示描述；歌曲详情显示封面，点击放大查看。格式、位深和采样率仍在详情。

## 实现范围与取舍

复用原生Compose、Media3、Android ICU、现有SQLite/JSON和共享歌曲列表；不添加网络权限、账号或外部字体/搜索依赖。iOS源码仍为1.0.1，本轮仅Android。音频输出、ReplayGain、EQ、CUE和云服务留在后续专业功能范围。

## 验证

逻辑测试覆盖专辑分组/多盘曲序、标签解析、队列插入/去重/随机顺序、计时到期/取消、歌词偏移边界及记录事件。原生用例检查ICU搜索、夜间配色、歌词校准、封面查看、最近播放和后台播放行为。构建Release/Debug及原生测试APK、lint，检查历史签名与16KB对齐。无手机时只记录编译结果，不宣称手势、后台计时或帧率已经实测。

依据：[此前调研](../research/2026-10-12-player-comparison.md)。研究基线1.0.5；本轮以已提交1.0.6逐项核对，歌单管理与排序不重复建设。
