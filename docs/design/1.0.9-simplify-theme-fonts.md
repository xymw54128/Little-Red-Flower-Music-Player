# Android 1.0.9：功能精简、花朵与多语言字体

日期：2026-10-13。用户明确要求六项更新；沿用 main、本地提交和现有签名。

- 预设封面仅保留新版十款花朵与心之花，蓝罂粟替换为蓝色矢车菊。旧预设编号稳定迁移，歌单照片保留。
- 移除睡眠计时、最近播放、自定义播放背景的入口和运行逻辑。音乐及用户照片不删除，旧备份中过时字段忽略；歌词、排序和歌单继续恢复。
- 移除文件变化观察与定时扫描。导入/授权时读取；随后仅手动刷新，每次重读所有标签并检查文件与同名歌词变化，包括单独导入的文件。
- 小红花作为媒体通知单色小图标；歌曲封面仍用于媒体封面。锁屏由系统渲染，具体位置和染色取决于 Android/HyperOS，不能通过应用控制所有样式。
- 完整指定主题容器与固定色等 Material 配色角色，弹出菜单、底部面板、对话框及所有子页使用当前应用主题和深浅模式。
- 歌词字体使用经授权的离线字体，重配中英日韩及数字的覆盖与同风格回退；选项中增加萌趣/圆润手写组合。实际 cmap、哈希、许可证和多语言预览作为检查证据，稀有字保留系统回退。

验证：旧 JSON/预设迁移、强制扫描和无自动触发、主题全部色角色、字体覆盖与渲染、媒体通知资源；Release、JVM、lint 和原生回归编译。未连接设备时不声称已执行锁屏、手势或帧率测试。iOS 与网页原型保持原版本，本轮仅 Android。
