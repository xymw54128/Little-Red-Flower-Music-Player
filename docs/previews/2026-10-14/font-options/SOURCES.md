## 子集修改与重现

字体内部名称与文件名已改为 P110A–P110M，原字形轮廓不变，原始版权与许可记录保留。13 份完整 SIL OFL 许可随目录提供。网页子集只含本页试读文字和可打印 ASCII，不能作为生产字体安装到 App；完整原始字体可从上方官方来源取得。

`build-preview-fonts.py` 从忽略的 `.toolchain/font-preview-110-google` 与 `.toolchain/font-preview-110-companions` 官方输入缓存及现有 Android 两个对照字库，生成字体、检查 cmap 并更新 HTML 内嵌字节。`inputs.json` 记录 11 个 Google 官方试读子集的 URL、许可、字节数与哈希。公开预览不需要缓存，本目录 HTML 和许可即可离线打开。

更换试读文字时，要重新通过 Google Fonts 官方 `text=` 请求取得对应字形，不能将系统后备字体的截图当作候选字形。字体方向选定后，还需要在 Android 上配置完整中／日／韩文配套并检查布局；本页不意味着移动端适配已完成。
